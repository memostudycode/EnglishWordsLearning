# EnglishWordsLearning
> Simple English vocabulary learning project｜简易英语单词学习项目

## 📖 Project Intro
This repository is for practicing English words memorization.
You can store word lists, review notes, vocabulary scripts and learning materials here.

本仓库用于英语单词背诵学习。
可以存放单词表、复习笔记、脚本代码以及各类学习资料。

## ✨ What can be put here
- Word lists（单词表：txt / csv / json）
- Learning notes 学习笔记
- Small code scripts for word quiz 单词小测试脚本
- Vocabulary review records 复习记录
